### 完整文案（校正版）

28岁的杨永兴，仅凭一招隔夜套利法，16个月把100万干到了1个亿。连炒股养家、张盟主、陈小群这些大佬都借鉴他的模式，江湖人称"短线快刀客"。他不打板、不追高，不到30岁资金上亿，这招也是小资金快速做大的最佳解法。今天我来帮大家拆解一下这大哥是怎么玩的，新手有可能可以在里面找到一些思路，看完你可以去感受感受。

我们先说一个反常识的结论：真正能赚到钱的时段，不是在开盘，而在收盘前的半小时。咱们一步一步拆解。

现在的A股，早盘半小时基本上就是被量化资金主导的。开盘拉一把诱多，把情绪点燃，散户一激动就冲进去追高，结果10点钟直接跳水，一记闷杀。而更狠的是A股是T+1的规矩——当天买了当天卖不掉，只能眼睁睁看着自己的账户一下子变绿，而且绿一整天。这就是九成散户天天亏钱的根本原因：错把最凶险的时段当成了黄金时段。

那真正的黄金时段呢？是在下午两点半之后，我给它起了个名字叫"黄金半小时"。因为到了两点半，当天该跌的股票早就跌透了，该涨的也已经站稳了，主力的底牌全部亮在盘面上，没有藏牌的空间。量化早就撤了，市场情绪也彻底冷静下来。你这个时候进场，直接规避掉当天九成的日内风险。

那么进场之后该怎么赚钱？靠的就是四个字——惯性溢价。尾盘冲高的接盘侠是谁？就是早上头脑一热追涨的人。你手里的筹码应该从容不迫地倒给他们，赚的就是这个确定性极高的溢价。今天进、明天出，不扛风险、不赌行情，只吃这一口稳稳的，这就是隔夜套利法的核心逻辑，也是杨永兴把T+1玩成T+0的秘密。

但要玩明白这招，你必须把一条铁律刻进脑子里，不然赚得再多都会吐回去：次日早盘必须清仓。除非是缩量涨停或者一字涨停，其他所有情况——不管你赚了七八个点，还是只够抵个手续费——一律无条件走人。没有这样一份交易纪律，你就是主力眼里送钱的机器。

杨永兴有一套隔夜套利的实战筛选法，一共八步环环相扣，少一步都有可能踩雷。按步骤顺序执行，胜率直接拉满。我先说一句实话：有的时候八步筛完，一个符合条件都没有，这也很正常。超短线最怕为了买而买，空仓也是一种操作，宁可错过不可做错。

第一步：卡时间。两点半之前所有的动作都是干扰项，只有在两点半到三点这半小时里筛选和下单，其他时间不看盘、不操作，避开盘中所有假信号。

第二步：看涨幅。只做主板，涨幅锁死在3%到5%这个区间——这就是性价比舒适区。涨幅太高就是追高风险大，涨幅太低说明没人拉，第二天没有惯性。哪怕超级行情，也绝对不碰5%以上的。这一条不守，前面努力全部白费。

第三步：看活性（涨停基因）。硬性指标：近20个交易日必须有过涨停。有过涨停说明主力资金关注过，有拉升的历史记忆。那些常年一潭死水的票，直接从自选股里删掉，不要有任何幻想。

第四步：过滤量比。剩下的票按量比从高到低排一遍，量比小于1的全部删掉。量比不够说明当天没有人气，没有人气的股票次日冲高的概率几乎为0。咱们不做僵尸股，只做活跃股。

第五步：看换手率。只留5%到10%这个区间的。低于5%说明资金不关注；高于10%要警惕，主力在派发筹码给散户接盘。5%到10%是主力在场且没跑的信号，这个位置跟着上车最稳。

第六步：看市值。总市值超过200亿的直接剔除——大盘股太重、弹性差、拉不动；低于50亿的也不要——小盘股容易踩雷爆雷。只做50亿到200亿中等市值的票，既有流动性又有弹性。

第七步：视觉关（分时图）。打开分时图看两个东西：①股价全天要稳稳站在分时均线（黄线）之上；②走势要强于大盘，能逆势走更好。说明当天所有进场的资金全部都是浮盈状态，没有套牢盘，多头完全主导，这种次日冲高的概率极大，惯性溢价基本锁死。

八步走完，选出的就是优质强势股了，但你还是不能直接买，得等一个精准的入场信号：个股创当天新高之后回踩分时均线，只要不跌破那条黄线，尾盘就果断进场——这个点位就是全天风险最低、赔率最高的买点。

整套逻辑说穿了其实很简单：层层过滤，选出有资金关注、走势强、上方阻力小的票，尾盘低吸进场，次日高点冲高就卖。不猜行情、不追逐热点，全靠规则吃饭。每次赚三个点到五个点，积小胜为大胜——这才是超短线复利的真相，也是小资金想快速做大可以去模拟的路线。

最后再强调一遍生死线：次日早盘必须全部清仓，纪律大于一切。今天要讲的内容，以上是我拆解的别人的实战精髓，没有一句废话，能听到多少全看你自己。关注我，后面还会继续拆解其他大佬的一些小手段、小法则。

### 完整文案（校正版）

我是杨永兴。很多人知道我是因为那个"16个月从100万做到一个亿"的传说，或者是因为后来在币圈那场闹得沸沸扬扬、至今没有结果的纠纷。但今天，我想抛开那些标签，就从一个普通交易者的角度，跟你聊聊我这20多年市场沉浮里最真实的想法、最核心的战法，以及那些刻骨铭心的教训。

我的起点和很多人一样，甚至更低。初中学历，最早就是跟着我爸在营业部里瞎看。他那个账户交到我手里的时候，已经亏得只剩不到两万块钱。我买的第一支股票跟绝大多数新手一样，买了就套，硬生生把那两万块熬成了8000块。那段日子很难熬，刚正视这种切肤之痛，让我明白了一个最朴素的道理：在这个市场上，你想活下去、想赚钱，就不能跟大多数人想的一样、做的一样。你得找到属于你自己的、哪怕只有一点点优势的生存方式。

2001年左右，我找到了第一个突破口。那时候上市公司刚开始搞业绩预告，很多人还没反应过来，我就琢磨：能不能在业绩正式公布前几天，提前埋伏进去那些业绩可能不错的公司，等业绩一出来，趁着大家还没反应过来、股价冲高的时候我先卖了。就这么简单的一个抢跑动作，让我第一次尝到了靠信息差和时间差赚钱的甜头。这让我意识到：交易的本质，很多时候不是比谁更聪明，而是比谁更快，比谁更早看到那一点点确定性的苗头。

到了2006年，大牛市来了，我的那套方法也终于进化成型，就是后来很多人说的"一夜持股法"或者"尾盘隔夜战法"。它的核心极其简单，就八个字：尾盘买入，次日早卖。听起来是不是太简单了？但简单背后的逻辑和纪律，才是真正考验人的地方。

我为什么一定要在尾盘、特别是下午两点半以后才动手？因为经过一天的博弈，该涨的该跌的基本都走出来了，市场的情绪和方向在尾盘会相对清晰。这时候进场，你能避开当天至少80%以上的不确定性风险——比如盘中突然的跳水，或者突发利空。我把这叫做只吃鱼身最肥、刺最少的那一段，鱼头和鱼尾肉少、刺多、风险大，我不要。

那么尾盘具体怎么选股？我给自己定下的死规矩一共六条，缺一不可，就像工厂的质检流水线：

第一，看涨幅。我只选下午两点半时涨幅在3%到5%之间的股票。涨太少——比如1%、2%——说明没人关注，股性不活，明天未必有冲高动力；涨太多——比如已经涨了7%、8%甚至涨停——短期获利盘太多，我尾盘追进去，第二天很容易被砸。3%到5%这个黄金区间，既有一定的上涨势头，又留出了次日冲高的空间。

第二，看基因。这支股票最近20个交易日必须有过涨停板。这说明它骨子里有活跃的基因，有资金关注和炒作的记忆。这种票在第二天早盘更容易被资金再次想起，形成联动。

第三，看量能。量比必须大于1。量比是什么？就是今天的成交活跃度跟过去平均水平的对比。大于1，说明今天有资金在干活，有真实的成交在推动股价；量比小于1的票，成交清淡，像一潭死水，你进去就是浪费时间，直接淘汰。

第四，看盘子大小。市值不能超过200亿。盘子太大——比如那些上千亿的巨无霸——需要的拉升资金是天文数字，不是我们这种体量资金能推动的。我选的票市值最好在50亿到200亿之间，船小好掉头，一点资金就能激起水花。

第五，看换手率。必须在5%到10%之间。低于5%，说明交易不够活跃、关注度太低；高于10%，甚至到20%、30%，那就说明里面的资金分歧巨大，很可能是有主力在趁着热闹出货，我进去就是接盘侠。5%到10%的换手，意味着有活跃度，但还没到疯狂出货的阶段。

第六，也是最重要的一条，看分时图。这支股票当天全天的股价，必须稳稳运行在分时均价线之上。均价线代表当天所有买入者的平均成本，股价全天都在均价之上，意味着当天大部分买入的人都是赚钱的，筹码结构稳定，抛压小。如果股价老是跌破均线，说明里面的人心涣散，随时可能多杀多，这种票走势不干净，我不碰。

符合这六条的股票，每天收盘前可能也就那么一两支，甚至有时候一支都没有——那就空仓、等待。等待本身就是交易的一部分。

买入了，然后呢？然后就是更重要的环节：卖。我的铁律是——第二天早上，最晚9:40之前，无论盈亏，必须清仓走人，绝对不恋战。绝对不把短线做成中线、中线做成长线、长线做成股东。

为什么是9:40之前？因为开盘后的半小时，是市场情绪最混乱、短线资金博弈最激烈的时候。很多资金，特别是现在流行的量化资金，喜欢在早盘制造脉冲式上涨来吸引跟风，然后反手卖出兑现利润。我前一天尾盘买入，就有了先手优势：第二天早盘只要股价有冲高，哪怕只冲高1%、2%，我立刻卖出锁定利润；如果低开呢，只要不符合预期，我也立刻止损，绝不留恋。

我追求的不是单笔暴利，而是极高的胜率和积小胜为大胜的复利。每一笔赚1%，看起来很少，但如果你能保持70%以上的胜率、严格控制亏损，时间的复利效应会可怕到让你自己都惊讶。我那16个月百倍的收益，就是这么一点点滚出来的。

这里面，最难的不是技术，而是心理——是对市场情绪的把握，和对抗自己的人性。尾盘买入，是克服盘中冲动交易的贪婪；早盘卖出，是克服"幻想赚更多"的贪婪，和"不忍心割肉"的恐惧。我见过太多人，买点可能跟我差不多，但就是因为早盘涨了还想多涨一点、跌了又幻想能拉回来，结果把好好的短线做成了深套。交易到最后，拼的就是纪律，是对自己定下的规则像机器一样去执行。

当然，这套方法也有它的局限性。当市场进入单边下跌的熊市时，什么技巧都很难奏效，这时候最好的操作就是空仓等待。后来，我的资金体量越来越大，尾盘那点成交量已经很难容纳我的进出，冲击成本太高，所以大概在2010年以后，我就逐渐淡出了二级市场的短线交易，转向了一级市场的股权投资。

时代在变，市场在变，没有一种方法可以永远有效，你必须不断进化。至于后来在币圈的经历，那又是另一个故事了——那是一个规则更模糊、波动更剧烈、人性也更赤裸的地方。那是一次惨痛的教训，它告诉我：无论技术如何精湛，市场的本质依然是对风险和信用的定价。在追求高回报的同时，永远不要低估潜在的规则之外的风险。

回顾这些年，我最大的感悟其实很简单：在这个市场里，你要做的不是预测明天是涨是跌——那是神仙做的事。你要做的是找到一套适合自己的、有概率优势的方法，然后像信仰一样去执行它。赚该赚的钱，躲该躲的坑。慢就是快，少就是多。股市里没有神话，只有对人性深刻的理解，和日复一日枯燥的纪律。希望我的这些经历和思考，能给你带来一点不一样的启发。
